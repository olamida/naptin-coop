STEP 1.2: Create Services

Create app/Services/LoanEligibilityService.php:

Methods:

public function calculateMaxEligibleAmount(Member $member, LoanProduct $product): array
- Gets member savings balance (sum savings_accounts balance)
- Gets default multiplier from loan_product.default_multiplier
- Checks if active override exists in member_loan_eligibility_overrides where member_id, loan_product_id, is_active, valid_from <= today, valid_until >= today or null
- If override exists, use custom_multiplier, else default
- Cap by product max_multiplier and max_amount
- Returns: [
    'savings_balance' => 200000,
    'default_multiplier' => 2,
    'applied_multiplier' => 2.5 (if override) else 2,
    'max_eligible' => 500000,
    'is_override' => true/false,
    'override_details' => override model or null,
    'formula' => '₦200k x 2.5 = ₦500k'
  ]

public function calculateTotalDeductionsPercent(Member $member, ?float $newLoanMonthlyRepayment = null): array
- Gets member monthly net salary from members table (add column monthly_net_salary if not exists) or from latest payroll record
- Calculates current total monthly deductions:
  - Savings monthly contribution (from savings setting)
  - Existing active loan repayments monthly (sum of repayment schedules where due_date >= today and loan status repaying)
  - Share contributions
  - Product purchase hire-purchase installments
- If $newLoanMonthlyRepayment provided, add it to total
- Calculates percent = (total_deductions / net_salary) * 100
- Gets default cap from payroll_deduction_caps where is_active = 33.33%
- Checks if member has custom_max_deduction_percent override active
- Returns: [
    'net_salary' => 150000,
    'current_deductions' => 30000,
    'current_percent' => 20,
    'new_loan_repayment' => 25000,
    'projected_total' => 55000,
    'projected_percent' => 36.67,
    'default_cap' => 33.33,
    'applied_cap' => 60 (if override) else 33.33,
    'hard_cap' => 66.67,
    'is_within_default' => false,
    'is_within_override' => true,
    'is_exceeds_hard' => false,
    'requires_override' => true
  ]

public function validateLoanApplication(Member $member, LoanProduct $product, float $amount, int $tenure): array
- Calls calculateMaxEligibleAmount, checks amount <= max_eligible, if not, return error "Amount exceeds eligible ₦X (Y x savings)"
- Calculates monthly repayment using amortization: (principal * monthly_interest * (1+interest)^tenure) / ((1+interest)^tenure -1) - use standard formula
- Calls calculateTotalDeductionsPercent with new repayment
- Checks if projected_percent > hard_cap (66.67) -> always deny, return "Exceeds hard cap 66.67% even with override - Salary would be insufficient"
- If projected_percent > applied_cap (default 33.33 or override) -> requires deduction_cap_override, return warning + requires EXCO approval with reason
- If amount requires multiplier override (applied_multiplier > default_multiplier) -> requires multiplier_override approval
- Returns validation result with flags: is_eligible, requires_multiplier_override, requires_deduction_override, monthly_repayment, total_percent, etc.
