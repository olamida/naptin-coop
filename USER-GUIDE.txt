1. INTRODUCTION & OVERVIEW
===========================================================================

The NAPTIN Staff Thrift Cooperative Society Application is a centralized
digital platform for managing all cooperative operations. It replaces
manual record-keeping with a secure, role-based web application.

WHAT THE SYSTEM DOES:
  - Registers and manages cooperative members
  - Tracks member savings (deposits, withdrawals, balances)
  - Manages loan applications, approvals, disbursements, and repayments
  - Tracks share purchases and holdings
  - Manages cooperative product catalog and purchase orders (cash & hire purchase)
  - Declares and distributes annual dividends
  - Compiles monthly payroll deductions
  - Generates printable receipts, statements, and reports
  - Provides a member self-service portal

WHO USES THE SYSTEM:
  - Super Administrator (full system access)
  - Administrators (cooperative management)
  - Secretary (member registration, record keeping)
  - Treasurer / Financial Secretary (savings, payroll, dividends)
  - Loan Officer (loan lifecycle management)
  - Teller (savings transactions, share purchases)
  - Members (self-service portal)

ACCESS URL: http://localhost/dev-angle/Starter-folder/naptin-coop/public

2. GETTING STARTED (LOGIN & NAVIGATION)
===========================================================================

2.1 LOGGING IN
--------------
  The login page uses the new slate-themed design with:
    - Clean white card on a slate-50 background
    - Company logo centred at top
    - Rounded-[16px] card with subtle border
    - Primary "Sign In" button in dark slate (#0F172A)
    - Password visibility toggle
    - "Remember me" and "Forgot Password?" links
    - Link to create an account or return to homepage

  Step 1: Open your web browser
  Step 2: Navigate to the application URL
  Step 3: The login page appears with the cooperative branding
  Step 4: Enter your email address and password
  Step 5: Click "Sign In" (dark slate button)

  Note: Members with linked accounts use the same login page.
        Your role determines what you see after login.

2.2 FORGOTTEN PASSWORD
----------------------
  Step 1: On the login page, click "Forgot Password?"
  Step 2: Enter your registered email address
  Step 3: Check your email for a password reset link
  Step 4: Click the link and set a new password
  Step 5: Log in with your new password

4. MODULE GUIDE: MEMBERS
===========================================================================

4.1 PURPOSE
-----------
  Register, track, and manage all cooperative members.

4.2 WHO CAN ACCESS
------------------
  - View members:    super-admin, admin, secretary, treasurer, loan-officer, teller
  - Create members:  super-admin, admin, secretary
  - Edit members:    super-admin, admin, secretary
  - Delete members:  super-admin only

4.3 MEMBER LIST PAGE (/members)
--------------------------------
  STATISTICS SHOWN:
    - Total members count
    - Active, Inactive, Retired, Suspended breakdowns

  FEATURES:
    - Search by first name, last name, or staff ID
    - Filter by region (dropdown)
    - Filter by status (active, inactive, retired, suspended)
    - Pagination (15 per page)

  ACTIONS AVAILABLE (permission-gated):
    - "+ Add Member"      → opens registration form          [create-members]
    - "Import"            → bulk import from Excel/CSV        [create-members]
    - "Export"            → download all members as Excel     [view-members]
    - "Bulk Status"       → select multiple, change status    [edit-members]
    - Click member row    → view member profile               [view-members]

  NOTE: Buttons/links are hidden if your role lacks the required permission.
        If you can see a page but not an action button, you lack permission.

4.4 MEMBER REGISTRATION (/members/create)
-----------------------------------------
  REQUIRED FIELDS:
    - Staff ID          (unique, e.g., "NAPTIN/0001")
    - First Name
    - Last Name
    - Region            (select from 8 regional centers)
    - Status            (active, inactive, retired, suspended)

  OPTIONAL FIELDS:
    - Middle Name
    - Email             (if provided → auto-creates user account)
    - Phone
    - Gender            (male, female)
    - Date of Birth
    - Employment Date
    - Retirement Date
    - Address
    - State of Origin
    - NIN (National Identification Number)
    - Grade Level
    - Monthly Salary
    - Monthly Savings
    - Photo             (JPEG/PNG, max 2MB)

  AUTOMATIC ACTIONS ON CREATION:
    1. Savings Account created   (balance: ₦0)
    2. Share Account created     (shares: 0, value: ₦0)
    3. If email provided:
       a. User account created with "member" role
       b. Welcome email sent with login credentials
    4. Member record stored

4.5 MEMBER PROFILE (/members/{id})
-----------------------------------
  TABS/VIEWS:
    - Personal Details (name, staff ID, region, salary, status, photo)
    - Savings (last 10 transactions + link to full history)
    - Shares (last 10 transactions + link to full history)
    - Loans (all loans with status badges)
    - Next of Kin (emergency contacts)

  ACTIONS:
    - Edit member
    - Add/remove next of kin
    - View full savings detail
    - View full loans detail
    - View full purchases detail
    - Delete member (only if no related data)

4.6 MEMBER DELETION RULES
--------------------------
  A member CANNOT be deleted if they have:
    - Savings account with transactions
    - Share account with transactions
    - Any loans (active or completed)
    - Any purchase orders
    - Any loan repayments
    - Any next of kin records
    - A linked user account

4.7 MEMBER IMPORT (/members/import)
------------------------------------
  FILE FORMAT: CSV or Excel (.xlsx, .xls)
  MAX SIZE: 10MB

  TEMPLATE COLUMNS:
    staff_id, first_name, last_name, middle_name, region,
    email, phone, gender, date_of_birth, employment_date,
    address, state_of_origin, nin, grade_level, monthly_salary, status

  REQUIRED COLUMNS: staff_id, first_name, last_name, region

  BEHAVIOR:
    - Each imported member automatically gets savings + share accounts
    - Members with email get user accounts created
    - Download template available with sample data

-----------------------------------------
  Shows all member savings accounts with current balances.

  FEATURES:
    - Search by member name, staff ID, or account number
    - Sort by: Latest, Highest balance, Lowest balance
    - Total balance summary shown at top

5.5 RECORDING A DEPOSIT (/savings/deposit)
-------------------------------------------
  Step 1: Click "Deposit" in sidebar
  Step 2: Select member from dropdown (active members only)
  Step 3: Enter amount (minimum ₦0.01)
  Step 4: Optional: upload payment evidence (receipt screenshot/photo)
  Step 5: Optional: add notes
  Step 6: Click "Record Deposit"

  WHAT HAPPENS:
    - Savings account balance is increased immediately
    - Transaction recorded with status: "completed"
    - If payment evidence uploaded: stored and viewable on transaction
    - Balance before and after are stored
    - Reference number generated
    - Redirected to accounts page with success message

5.6 RECORDING A WITHDRAWAL (/savings/withdraw)
-----------------------------------------------
  Step 1: Click "Withdraw" in sidebar
  Step 2: Select member from dropdown
  Step 3: Enter amount (must not exceed available balance)
  Step 4: Optional: add notes
  Step 5: Click "Submit Withdrawal Request"

  WHAT HAPPENS:
    - Transaction created with status: "PENDING"
    - Balance is NOT deducted yet
    - Goes to pending approval queue
    - Treasurer must approve before funds are released

  VALIDATION:
    - Amount must not exceed member's savings balance
    - If insufficient balance: error message shown

5.7 WITHDRAWAL APPROVAL (/savings/pending-withdrawals)
--------------------------------------------------------
  Step 1: Navigate to Pending Withdrawals (sub-nav tab or sidebar)
  Step 2: Review pending requests (member name, amount, date)
  Step 3: For each request, choose:
    - APPROVE:  Deducts balance, marks completed, sends notification
    - REJECT:   Requires rejection reason, marks rejected, sends notification

  VALIDATION ON APPROVAL:
    - System re-checks balance is sufficient
    - If balance changed since request: error shown

5.8 SAVINGS IMPORT
------------------
  File: CSV or Excel
  Required columns: staff_id, amount
  Optional: type (deposit/withdrawal), transaction_date, notes

6.5 LOAN LIFECYCLE
------------------
  ┌─────────┐    ┌──────────┐    ┌───────────┐    ┌──────────┐    ┌───────────┐
  │ PENDING  │───>│ APPROVED │───>│ DISBURSED │───>│ REPAYING │───>│ COMPLETED │
  └─────────┘    └──────────┘    └───────────┘    └──────────┘    └───────────┘
       │              │               │
       v              v               v
  ┌──────────┐  ┌──────────┐   ┌───────────┐
  │ REJECTED │  │ REJECTED │   │ DEFAULTED │
  └──────────┘  └──────────┘   └───────────┘

  STATUS DEFINITIONS:
    Pending    → Application submitted, awaiting approval
    Approved   → Approved by loan officer, awaiting disbursement
    Disbursed  → Funds released to member, repayment period started
    Repaying   → Member is making repayments
    Completed  → All payments received, loan fully paid
    Rejected   → Application rejected (reason required)
    Defaulted  → Loan past due, marked by administrator

6.6 CREATING A LOAN (/loans/create)
------------------------------------
  Step 1: Select member (active members only)
  Step 2: Select loan product (optional — provides defaults)
  Step 3: Enter loan amount
  Step 4: Enter interest rate (%)
  Step 5: Enter tenure (months)
  Step 6: Optional: select guarantors
  Step 7: Optional: enter purpose
  Step 8: Click "Submit Application"

  LOAN NUMBER FORMAT: REG/YYYY/XXXXXX
    Example: REG/2026/000015

  AUTOMATIC CALCULATIONS:
    Monthly Repayment = (Amount × (1 + Rate%)) ÷ Tenure (rounded to 2 decimals)

    Example: ₦100,000 loan at 5% interest, 12 months:
      Total with interest = ₦100,000 × 1.05 = ₦105,000
      Monthly repayment  = ₦105,000 ÷ 12   = ₦8,750.00

  VALIDATION (if loan product selected):
    - Amount within product's min/max range
    - Tenure within product's max term
    - Member hasn't exceeded max loans per member limit
    - Member's total outstanding hasn't exceeded max total amount

6.7 GUARANTOR SYSTEM
---------------------
  When a loan product requires guarantors:
    1. System creates LoanGuarantor records for each selected guarantor
    2. Notification sent to each guarantor member
    3. Guarantors must ACCEPT before loan can be approved
    4. Admin can accept/decline on behalf from loan detail page

  GUARANTOR STATUS OPTIONS:
    - Pending:  awaiting response
    - Accepted: guarantor agreed
    - Declined: guarantor declined

  RULE: ALL guarantors must accept before loan can be approved.

6.8 LOAN APPROVAL (/loans/{id}/approve)

6.11 RECORDING A REPAYMENT (/loans/{id}/repayment)
---------------------------------------------------
  Step 1: Open loan detail page
  Step 2: Click "Record Repayment"
  Step 3: Enter amount
  Step 4: Select payment method:
          - Cash
          - Bank Transfer
          - Salary Deduction
          - Savings Deduction
  Step 5: Enter payment date
  Step 6: Optional: add notes
  Step 7: Click "Record Payment"

  AUTOMATIC SPLIT LOGIC:
    The system splits each payment into principal and interest:
      interest_portion  = amount × (rate / (1 + rate))
      principal_portion = amount - interest_portion

    Example: ₦100,000 payment at 5% interest rate:
      interest  = ₦100,000 × (0.05 / 1.05) = ₦4,761.90
      principal = ₦100,000 - ₦4,761.90 = ₦95,238.10

  WHAT HAPPENS:
    - Repayment record created with reference: LN/REPAY/XXXXXXXX
    - Loan outstanding decreased by principal portion
    - If outstanding reaches ₦0 → status changes to "completed"
    - If completed → notification sent to member

6.12 LOAN DETAIL PAGE (/loans/{id})

  AUDIT TRAIL ENTRIES:
    - submitted:  when application was created
    - approved:   when approved
    - rejected:   when rejected (with reason)
    - disbursed:  when funds released
    - note_added: when admin adds notes

    - Cannot respond to your own loan's guarantor request
    - Response is final (cannot be changed)

13.8 MEMBER PRODUCT ORDERING
----------------------------
  Step 1: Click "Shop" in top menu (green "New" badge if new products exist)
  Step 2: Browse products (grid view with search, sort, price filter)
  Step 3: Click "Add to Cart" (AJAX — no page refresh, live badge updates)
  Step 4: Click cart icon in top menu to view cart
  Step 5: Adjust quantities or remove items (all AJAX-powered)
  Step 6: Proceed to Checkout
  Step 7: Select payment type (Cash or Hire Purchase)
  Step 8: Confirm order

  WHAT HAPPENS:
    - PurchaseOrder records created
    - Stock decremented
    - Cash orders → approved immediately
    - Hire purchase → pending for admin approval

  PORTAL CART FEATURES:
    - Add to cart without page reload (AJAX)
    - Update quantity with +/- buttons (instant update)
    - Remove items (instant update)
    - Clear cart button
    - Live cart count badge in top menu (shared across pages via CustomEvent)
    - Total calculated in real-time

13.9 MEMBER NOTIFICATIONS
-------------------------
  TOP MENU DROPDOWN:
    - Bell icon with unread count badge
    - Click to open dropdown showing 5 most recent notifications
    - Each shows icon, message, time ago, unread dot
    - "Mark all read" button in dropdown header
    - "View all notifications" link at bottom

  FULL NOTIFICATIONS PAGE (/my/notifications):
    - Complete list of all notifications
    - Mark individual as read
    - Mark all as read
    - Types of notifications:
      - Guarantor requests (group_add icon)
      - Loan status changes (account_balance icon)
      - Withdrawal status changes (savings icon)
      - Savings deposit recorded (savings icon)
      - Share purchased (trending_up icon)
      - Dividend declared (diversity_3 icon)
      - Payroll compiled (payments icon)

14.3 USER MANAGEMENT (/admin/users)
------------------------------------
  CRUD operations for system user accounts.

  CREATE USER:
    - Name
    - Email (unique)
    - Password (min 8 chars, must confirm)
    - Role (select from dropdown)

  EDIT USER:
    - Change name, email
    - Change password (optional)
    - Change role

  SPECIAL ACTIONS:
    - Reset Password: generates temp password, sends email notification
    - Delete: cannot delete your own account

  VALIDATION:
    - Email must be unique
    - Cannot delete yourself
    - Cannot reset your own password from here

14.4 ROLES & PERMISSIONS (/admin/roles)
----------------------------------------
  Manage roles and their associated permissions.

  VIEW: List all roles with their permissions
  CREATE: Name + select permissions from grouped checkboxes
  EDIT: Change name, toggle permissions
  DELETE: Cannot delete "super-admin" role

  PERMISSION GROUPS:
    Dashboard (1), Members (4), Next of Kin (1), Savings (3),
    Loans (6), Loan Products (2), Shares (2), Products (6),
    Dividends (5), Payroll (4), Reports (1), Admin (2)

14.5 REGIONAL CENTERS (/admin/regions)
---------------------------------------
  Manage cooperative office locations.

  FIELDS:
    - Name (unique)
    - Code (unique, e.g., "ABJ")
    - Zone
    - Headquarters
    - Address
    - Phone
    - Email

  DEFAULT REGIONS (8):
    Abuja (ABJ), Lagos (LAG), Port Harcourt (PHC), Kano (KAN),
    Enugu (ENU), Jos (JOS), Ibadan (IBD), Kaduna (KAD)

14.6 LOAN PRODUCTS (/admin/loan-products)
------------------------------------------
  Configure loan types with validation rules.

  FIELDS:
    - Name (e.g., "Regular Loan")
    - Slug (auto-generated)
    - Description
    - Min Amount (₦)
    - Max Amount (₦)
    - Interest Rate (%)
    - Repayment Method (flat / reducing_balance)
    - Max Term (months)
    - Processing Fee (%)
    - Requires Guarantors (toggle)
    - Requires Collateral (toggle)
    - Max Loans Per Member
    - Max Total Amount Per Member
    - Enabled (toggle)

  DEFAULT PRODUCTS (4):
    Regular Loan, Emergency Loan, Educational Loan, Special Loan

  VALIDATION ON LOAN APPLICATION:
    - Amount must be within min/max range
    - Tenure must not exceed max term
    - Member must not exceed max loans per member
    - Member's total outstanding must not exceed max total amount

14.7 STOCK MANAGEMENT (/admin/stock)

  Adjust product stock levels.

17. GLOSSARY OF TERMS

  Term                    Definition
  ─────────────────────── ─────────────────────────────────────────────
  Balance                 The current amount in a savings account
  Checkout                The process of finalizing a purchase order
  Compile Payroll         Calculate expected deductions for a period
  Disbursement            Release of approved loan funds to member
  Dividend                Annual profit distribution to shareholders
  Dividend Distribution   Per-member payout calculated from shares
  Guaranteed              A member who backs a loan application
  Hire Purchase           Buying on installment plan
  Loan Product            A configurable loan type with rules
  Loan Number             Unique ID: REG/YYYY/XXXXXX
  Outstanding             Remaining loan amount to be repaid
  Order Group             Groups items from single cart checkout
  Payroll Deduction       One member's deductions in a payroll run
  Payroll Number          Unique ID for monthly payroll run
  Portion                 Part of repayment (principal or interest)
  Principal               The original loan amount (excluding interest)

  Share Price             Cost per share (default ₦100)
  Staff ID                Unique member identifier (e.g., NAPTIN/0001)
  Status                  Current state of a record in its lifecycle
  Tenure                  Loan repayment period in months

18. QUICK REFERENCE: ROLE CAPABILITIES
===========================================================================

SUPER-ADMIN — Full system access
  ✓ Everything below, plus:
  ✓ Delete members
  ✓ Delete loans
  ✓ Manage all admin functions

ADMIN — Full cooperative management
  ✓ Register/edit members
  ✓ Record savings deposits and withdrawals
  ✓ Create/approve/disburse loans
  ✓ Record loan repayments
  ✓ Manage products and purchase orders
  ✓ Declare/calculate/approve/distribute dividends
  ✓ Compile/upload/export payroll
  ✓ Generate reports
  ✓ Manage users, roles, regions, loan products
  ✓ Stock management, backup, statistics

SECRETARY — Records and documentation
  ✓ View all modules
  ✓ Register and edit members
  ✓ Manage next of kin
  ✗ Cannot touch money (savings, shares)
  ✗ Cannot manage loans
  ✗ Cannot manage products or payroll

TREASURER — Financial operations
  ✓ Record savings deposits and withdrawals
  ✓ Approve/reject pending withdrawals
  ✓ Purchase shares
  ✓ Disburse loans
  ✓ Record loan repayments
  ✓ Create purchase orders
  ✓ Declare/calculate dividends
  ✓ Compile/upload/export payroll
  ✗ Cannot approve loans
  ✗ Cannot manage users or roles

LOAN OFFICER — Loan lifecycle
  ✓ Create loan applications
  ✓ Approve or reject loans
  ✓ Disburse approved loans
  ✓ Record loan repayments
  ✓ Import loan repayments
  ✗ Cannot touch savings
  ✗ Cannot manage products or payroll

TELLER — Front-desk transactions
  ✓ Record savings deposits
  ✓ Submit withdrawal requests
  ✓ Purchase shares
  ✗ Cannot approve withdrawals
  ✗ Cannot manage loans
  ✗ Cannot manage products or payroll

MEMBER — Self-service portal only
  ✓ View dashboard (personal stats)
  ✓ View savings history
  ✓ Request deposits (with payment evidence upload, pending approval)
  ✓ Request withdrawals (pending approval)
  ✓ View loans and repayment schedule
  ✓ Apply for loans (select product, guarantors, auto-calc with interest)
  ✓ View shares
  ✓ View purchases
  ✓ Browse products and order (AJAX cart, live updates)
  ✓ Accept/decline guarantor requests
  ✓ View and manage notifications (dropdown + full page)
  ✓ Edit profile (name, email, password, photo)
  ✗ Cannot access any admin functions
  ✗ Cannot view other members' data
